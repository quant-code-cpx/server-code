```text

│   ├── stock-chip.repository.ts

│   └── stock-shareholder-tool.facade.ts

```

Module 只导出五个 Facade。`AgentModule` import `StockDeepResearchModule`，不得重复 provide 内部 Service。

`StockAnalysisService.getChipDistribution()` 当前会在无真实筹码数据时自动估算；`getMarginData()` 当前会 catch 所有数据库异常并返回 `available=false`；`StockFinancialService` 还可能在本地无分红时触发同步。Agent Facade 不得直接沿用这些行为：

- 估算必须由 `sourcePolicy=ALLOW_LOCAL_ESTIMATE` 显式开启。
- 数据不存在和数据库失败必须分开。
- 事件和股东 Tool 永不触发同步。

## 4. 公共契约

所有输入 `additionalProperties=false`，共同字段：

| 字段       | 类型     | 约束                                   |
| ---------- | -------- | -------------------------------------- |
| `tsCode`   | string   | 必填，`^\d{6}\.(SH\|SZ\|BJ)$`          |
| `asOfDate` | ISO date | 可选，解析为不晚于该日的最近可用数据日 |

共同输出元数据：

```ts
interface StockDeepResearchMeta {
  tsCode: string
  requestedAsOfDate: string | null
  dataThrough: string | null
  coverageStart: string | null
  timezone: 'Asia/Shanghai'
}
```

不同 section 使用：

```ts
type SectionResult<T> =
  | { status: 'OK'; data: T; error: null }
  | { status: 'NOT_REQUESTED'; data: null; error: null }
  | { status: 'NOT_READY'; data: null; error: { code: string; message: string } }
  | { status: 'ERROR'; data: null; error: { code: string; message: string } }
```

核心 section 全部失败时 Tool 返回 typed error；可选 section 失败时 fail-soft，并在 ToolResult warnings 中列明。

## 5. `get_stock_chip_profile@1`

### 5.1 输入

| 字段               | 类型     | 默认          | 约束                                      |
| ------------------ | -------- | ------------- | ----------------------------------------- |
| `tsCode`           | string   | —             | 必填                                      |
| `asOfDate`         | ISO date | 最新 READY    | 可选                                      |
| `sections`         | enum[]   | `SUMMARY`     | `SUMMARY,DISTRIBUTION,HISTORY`；1–3、去重 |
| `historyTradeDays` | integer  | 60            | 1–500，仅 HISTORY                         |
| `maxPriceBuckets`  | integer  | 200           | 20–500，仅 DISTRIBUTION                   |
| `sourcePolicy`     | enum     | `STORED_ONLY` | `STORED_ONLY,ALLOW_LOCAL_ESTIMATE`        |

### 5.2 输出

```ts
interface StockChipProfileData {
  meta: StockDeepResearchMeta
  summary: SectionResult<{
    tradeDate: string
    currentPrice: number | null
    cost5Pct: number | null
    cost15Pct: number | null
    medianCost: number | null
    cost85Pct: number | null
    cost95Pct: number | null
    weightedAverageCost: number | null
    winnerRate: number | null
    source: 'TUSHARE_CYQ_PERF'
    isEstimated: false
  }>
  distribution: SectionResult<{
    tradeDate: string
    totalBuckets: number
    returnedBuckets: number
    sampling: 'NONE' | 'WEIGHTED_BUCKET_MERGE'
    buckets: Array<{ price: number; percent: number | null }>
    source: 'TUSHARE_CYQ_CHIPS' | 'LOCAL_OHLCV_ESTIMATE'
    isEstimated: boolean
    algorithmVersion: string | null
  }>
  history: SectionResult<
    Array<{
      tradeDate: string
      medianCost: number | null
      weightedAverageCost: number | null
      winnerRate: number | null
    }>
  >
}
```

规则：

- SUMMARY 和 HISTORY 只读 `CyqPerf`。
- DISTRIBUTION 优先读同日 `CyqChips`。
- `STORED_ONLY` 且无分布时 section 返回 NOT_READY，不自动估算。
- `ALLOW_LOCAL_ESTIMATE` 才可调用抽取后的纯计算服务；返回 `isEstimated=true`、`algorithmVersion=chip-estimation.v1` 和 `ESTIMATED_FROM_OHLCV` warning。
- 估算不得覆盖真实记录；同次响应不同 section 可拥有不同来源。
- price bucket 超限使用确定性相邻桶合并，保留总 percent，禁止随机抽样。

### 5.3 错误与 Policy

| 场景                              | 错误               |
| --------------------------------- | ------------------ |
| 股票不存在/请求日期早于 2018 覆盖 | `DATA_NOT_FOUND`   |
| 股票存在但请求 section 尚未同步   | `DATA_NOT_READY`   |
| DB 错误                           | `UPSTREAM_FAILED`  |
| 输入或 section 组合非法           | `INVALID_ARGUMENT` |

Policy：READ、PUBLIC_MARKET_DATA、20 秒、2 attempts、maxRows 1,000、cost MEDIUM。

### 6.1 输入

| 字段                | 类型     | 默认       | 约束                   |
| ------------------- | -------- | ---------- | ---------------------- |
| `tsCode`            | string   | —          | 必填                   |
| `asOfDate`          | ISO date | 最新 READY | 可选                   |
| `sections`          | enum[]   | `SUMMARY`  | `SUMMARY,HISTORY`；1–2 |
| `lookbackTradeDays` | integer  | 60         | 1–500                  |

### 6.2 输出

```ts
interface StockMarginHistoryData {
  meta: StockDeepResearchMeta & {
    marketPriceDataThrough: string | null
    lagVsStockTradingDays: number | null
  }
  summary: SectionResult<{
    latestFinancingBalance: number | null
    latestSecuritiesLendingBalance: number | null
    latestTotalBalance: number | null
    financingNetBuy5d: number | null
    financingNetBuy20d: number | null
    financingBalanceChange5dPct: number | null
    financingBalanceChange20dPct: number | null
    trend: 'UP' | 'DOWN' | 'STABLE' | 'INSUFFICIENT_DATA'
  }>
  history: SectionResult<
    Array<{
      tradeDate: string
      financingBalance: number | null
      financingBuy: number | null
      financingRepay: number | null
      financingNetBuy: number | null
      lendingBalance: number | null
      lendingSellVolume: number | null
      lendingRepayVolume: number | null
      lendingRemainingVolume: number | null
      totalBalance: number | null
      qfqClose: number | null
    }>
  >
  units: {
    balances: 'CNY'
    volumes: 'SHARE'
    close: 'CNY_PER_SHARE'
    changes: 'PERCENT'
  }
}
```

规则：

- 以两融数据最新日作为 `dataThrough`，不能用股票日线最新日冒充。
- `lagVsStockTradingDays>0` 返回 `MARGIN_DATA_LAGS_MARKET`。
- 5/20 日变化按实际两融观测日，不按自然日。
- `trend` 固定规则：20 日余额变化绝对值 <1% 为 STABLE；>=1% 为 UP；<=-1% 为 DOWN；有效点不足 20 为 INSUFFICIENT_DATA。算法版本 `margin-trend.v1`。
- 移除现有 catch-all；数据库异常返回 `UPSTREAM_FAILED`，空数据返回 `DATA_NOT_READY`。

Policy：READ、PUBLIC_MARKET_DATA、15 秒、2 attempts、maxRows 500、cost MEDIUM。

## 7. `get_stock_relative_strength@1`

### 7.1 输入

| 字段                | 类型     | 默认          | 约束                                            |
| ------------------- | -------- | ------------- | ----------------------------------------------- |
| `tsCode`            | string   | —             | 必填                                            |
| `benchmarkCode`     | string   | `000300.SH`   | 指数代码；必须在 `IndexBasic/IndexDaily` 有数据 |
| `asOfDate`          | ISO date | 共同 READY 日 | 可选                                            |
| `lookbackTradeDays` | integer  | 120           | 20–1,250                                        |
| `sections`          | enum[]   | `SUMMARY`     | `SUMMARY,SERIES`；1–2                           |

### 7.2 计算定义

新增 `RelativeStrengthCalculationService`，输入已对齐的个股 QFQ close 和指数 close：

```text
dailyReturn[t] = close[t] / close[t-1] - 1
cumulativeReturn[t] = product(1 + dailyReturn[1..t]) - 1
activeReturn[t] = stockDailyReturn[t] - benchmarkDailyReturn[t]
excessTotal = stockCumulativeReturn[last] - benchmarkCumulativeReturn[last]
beta = covariance(stockDailyReturn, benchmarkDailyReturn) / variance(benchmarkDailyReturn)
informationRatio = mean(activeReturn) / sampleStd(activeReturn) * sqrt(252)
maxDrawdown = min(stockNormalizedNav / runningPeak - 1)
```

- 样本标准差使用 `n-1`。
- 指数方差为 0、有效共同日少于 20 时 beta/IR 返回 null。
- 算法版本 `relative-strength.v1`；任何公式变化发布 Tool/算法新版本。

### 7.3 输出

```ts
interface StockRelativeStrengthData {
  meta: StockDeepResearchMeta & {
    benchmarkCode: string
    benchmarkName: string | null
    commonTradeDays: number
    adjustment: 'QFQ_RATIO'
    algorithmVersion: 'relative-strength.v1'
  }
  summary: SectionResult<{
    stockTotalReturn: number | null
    benchmarkTotalReturn: number | null
    excessReturn: number | null
    excess20d: number | null
    annualizedVolatility: number | null
    maxDrawdown: number | null
    beta: number | null
    informationRatio: number | null
  }>
  series: SectionResult<
    Array<{
      tradeDate: string
      stockNormalizedNav: number
      benchmarkNormalizedNav: number
      stockCumulativeReturn: number
      benchmarkCumulativeReturn: number
      cumulativeExcessReturn: number
    }>
  >
}
```

Policy：READ、PUBLIC_MARKET_DATA、20 秒、2 attempts、maxRows 1,250、cost HIGH；Provenance 的 `sourceType=PROGRAM_CALCULATION`。

## 8. `get_stock_events@1`

### 8.1 事件目录

```text
EARNINGS_FORECAST
DISCLOSURE
DIVIDEND
REPURCHASE
SHARE_FLOAT
SUSPEND
TOP_LIST
BLOCK_TRADE
```

### 8.2 输入

| 字段        | 类型     | 默认          | 约束                       |
| ----------- | -------- | ------------- | -------------------------- |
| `tsCode`    | string   | —             | 必填                       |
| `sections`  | enum[]   | 全部          | 1–8、去重                  |
| `startDate` | ISO date | `endDate-90d` | 与 endDate 最大跨度 366 天 |
| `endDate`   | ISO date | 当前日        | 不得早于 startDate         |
| `asOfDate`  | ISO date | 当前日        | 只返回在该日已知的事件     |
| `page`      | integer  | 1             | 1–100                      |
| `pageSize`  | integer  | 50            | 1–100                      |

### 8.3 点时规则

| 事件     | `eventDate`                         | `knownAt`                                       |
| -------- | ----------------------------------- | ----------------------------------------------- |
| 业绩预告 | `annDate`                           | `annDate`                                       |
| 财报披露 | `actualDate` 优先，否则 `preDate`   | 实际披露用 `actualDate`；计划用对应计划记录时间 |
| 分红     | `exDate`/`recordDate`，按返回子类型 | `annDate`                                       |
| 回购     | `annDate` 或实施截止日              | `annDate`                                       |
| 解禁     | `floatDate`                         | `annDate`                                       |
| 停复牌   | `tradeDate`                         | `tradeDate`                                     |
| 龙虎榜   | `tradeDate`                         | `tradeDate` 收盘后                              |
| 大宗交易 | `tradeDate`                         | `tradeDate` 收盘后                              |

Repository 先执行 `knownAt <= asOfDate`，再按 `eventDate` 范围筛选。没有可靠 `knownAt` 的行必须排除或返回 `POINT_IN_TIME_UNVERIFIED`，不能用于历史因果陈述。

### 8.4 输出

```ts
interface StockEventItem {
  id: string
  type: string
  eventDate: string
  knownAt: string | null
  tsCode: string
  title: string
  status: string | null
  reportPeriod: string | null
  values: Record<string, string | number | boolean | null>
  sourceModel: string
  pointInTimeVerified: boolean
}

interface StockEventsData {
  meta: StockDeepResearchMeta
  sections: string[]
  total: number
  page: number
  pageSize: number
  items: StockEventItem[]
}
```

- 排序固定 `eventDate DESC, type ASC, id DESC`。
- `values` 只允许每类白名单字段，不能把整行 Prisma 对象返回给模型。
- 摘要/原因文本单字段最多 2,000 字；截断返回字段级 warning。
- 不调用 `StockFinancialService.getDetailDividendFinancing()` 的在线同步 fallback。

Policy：READ、PUBLIC_MARKET_DATA、20 秒、2 attempts、maxRows 100、cost MEDIUM。

`ShareholderPeriod` 固定包含 `reportPeriod`、`latestAnnouncementAt`、最多 10 条 holder，以及持股数量/比例/变动/类型。

- HOLDER_COUNT、TOP10、TOP10_FLOAT、TRADES 只返回 `annDate <= asOfDate`。

- 历史回测或“当时是否已知”问题不得使用未验证的 PLEDGE section。
- holderName 作为外部文本，输出前做长度限制和控制字符清理，不允许进入系统指令。

## 12. 测试与验收

### 12.1 独立业务测试

- 筹码：真实/估算不混淆；分桶合并前后 percent 总量一致。
- 两融：用手算数据验证 5/20 日净买入和余额变化；数据库错误不能变成“无数据”。
- 相对强弱：用 4–30 个可手算收益点验证复利、beta、IR、回撤和共同日对齐。
- 事件：公告日晚于 asOf 的记录不可见；同事件排序分页无重复遗漏。
- 股东：同报告期多公告只取 asOf 时点可见版本；质押 warning 强制存在。

### 12.2 安全与契约

- Schema 拒绝未知字段、超长区间、未知 section 和非法代码。
- 五个 Tool 依赖图无 Tushare Client/API/Sync Service。
- Repository 不接受动态表名/列名。
- 输出文本长度、null、单位、来源、warning 与 ToolResult 一致。

### 12.3 真实库黑盒

至少 30 只股票，覆盖：有/无筹码分布、有/无两融、停牌、近期事件、多个股东报告期、北交所股票。

业务问题：

```text
茅台最新获利盘和中位成本是多少？
某股票融资余额最近 20 个交易日如何变化？
特变电工近一年相对沪深300表现如何？
这家公司未来 90 天有哪些已公告事件？
最新股东人数、前十大股东和质押比例如何？
```

每个问题必须路由到正确 Tool；Agent Run 前后 Tushare 请求增量为 0。

### 12.4 性能目标

| Tool                 |     P95 |
| -------------------- | ------: |
| 筹码 SUMMARY/HISTORY | <500 ms |
| 500 桶分布           |    <1 s |
| 两融 500 日          | <800 ms |
| 相对强弱 1,250 日    |  <1.5 s |
| 事件/股东一页        | <800 ms |
