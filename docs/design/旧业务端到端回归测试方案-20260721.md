## 3. 共同业务规则

| 规则编号 | 规则                                                 | 业务依据          | 测试影响                         |
| -------- | ---------------------------------------------------- | ----------------- | -------------------------------- |
| R-001    | 所有业务 Controller 使用 POST，查询条件走 Body       | 当前公开 API 契约 | 禁止沿用旧 GET/路径参数调用      |
| R-002    | 用户只能读写自己的策略、回测、组合、预警和信号配置   | 租户隔离          | 每条资源链至少验证一次跨用户拒绝 |
| R-003    | 日期统一为 `YYYYMMDD`，业务日按 `Asia/Shanghai` 解释 | 仓库日期规范      | 覆盖非法格式与 UTC/上海跨日      |
| R-004    | 金融数值用固定数据独立手算，`null` 不得污染聚合      | 数据正确性        | 禁止只断言非空或复制实际输出     |
| R-005    | 复合写操作必须原子；失败不得留下半成品               | 资金与持仓一致性  | 回测导入、创建链路检查回滚       |
| R-006    | 重复请求/扫描不得产生重复业务事实                    | 幂等性            | 验证验证码消费、扫描和信号去重   |
| R-007    | 每 suite 使用独立 PostgreSQL/Redis，结束清理         | 测试隔离          | 禁止写开发库和主 Redis           |

## 4. 接口契约冻结

| 流程           | 核心 POST 接口                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 认证           | `/api/auth/captcha`、`/api/auth/login`、`/api/auth/refresh`、`/api/auth/logout`、`/api/user/profile/detail`                                            |

| 因子→策略→回测 | `/api/factor/library`、`/factor/screening`、`/factor/backtest/save-as-strategy`、`/api/strategies/detail`、`/api/strategies/run`                       |
| 回测→组合      | `/api/portfolio/apply-backtest`、`/detail`、`/rebalance-plan`                                                                                          |

已修缺陷：`LEG-SB-20260721-001`（S2/P1）——净值接口原先直接返回账户权益金额，首点为 `100000` 而非归一化 NAV `1`。现仅在 API 输出层按首日权益归一化；数据库仍保存真实权益金额，防回归单测 25/25、Flow 2 E2E 4/4、TypeScript 与 production build 均通过。

- `LEG-FSB-20260721-001`（S1/P0）：保存指数股票池时错误写为 `CUSTOM` 且丢失原指数代码，后续策略回测无法加载股票池。现映射为 `HS300/CSI500/CSI1000/SSE50`，同时保存原始 `universeCode`。
- `LEG-FSB-20260721-002`（S1/P0）：`FACTOR_SCREENING_ROTATION` 从全量因子快照选股，未限制在回测引擎已加载 universe，池外高排名股票可进入目标集合。现按历史行情 universe 过滤后再执行条件、排序和 TopN。
- `LEG-FSB-20260721-003`（S2/P1）：universe DTO 只校验字符串，注入样式和不受支持指数未被拒绝。现增加指数代码格式、历史成分存在性与回测支持范围校验；失败不创建策略或 Run。
- `LEG-AS-20260721-001`（S1/P0）：价格扫描没有业务唯一键，并发或重复扫描会重复写历史、递增 `triggerCount`、发送通知。现增加 `(ruleId, tradeDate, tsCode)` 唯一约束；迁移清理历史重复事实并按扫描批次收敛计数；运行时使用事务化 `createMany(skipDuplicates)`。
- `LEG-AS-20260721-002`（S1/P0）：信号显式日期按上海午夜转为 `Date`，写入 Prisma `@db.Date` 后落到 UTC 前一日。现统一使用 `parseCompactTradeDateToUtcDate()`，数据库和 API 均保持 `YYYYMMDD` 日历日。
- `LEG-AS-20260721-003`（S1/P0）：首次激活的 `lastSignalDate=null` 被 `NOT lastSignalDate=目标日` SQL 三值逻辑排除，策略永远不生成首个信号。现显式查询 `lastSignalDate IS NULL OR lastSignalDate != 目标日`。
