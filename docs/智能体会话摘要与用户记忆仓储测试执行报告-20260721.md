## 1. 本轮目标

- 实现 owner-scoped 摘要与记忆 Repository。
- 用真实 PostgreSQL 验证事务回滚、CAS、版本推进、跨租户、TTL、敏感策略和并发唯一性。
- 不触碰主 PostgreSQL/Redis，不提前实现 Service/API/Context Builder。

## 2. 业务理解摘要

| 项目     | 结论                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 业务场景 | 长会话追加版本摘要；用户候选记忆经显式确认后进入长期上下文                           |
| 核心规则 | 历史不可覆盖；多步写入原子；expected version CAS；active 记忆唯一；删除/过期立即失效 |
| 关键风险 | 半提交、last-write-wins、跨租户、未确认敏感记忆、过期 unique 占用、版本回退          |
| 待澄清   | 公共分页 DTO、到期清理任务和 API 错误映射留到 Service/API 阶段                       |
