## 3. 关键业务结果

### 3.1 服务端全链

隔离 PostgreSQL 下实际完成：

- HTTP 创建会话与消息；
- Run 入队、Worker claim、Tool 执行、模型 PLAN/SYNTHESIZE；
- 审计、引用、消息与唯一终态持久化；
- SSE 重放、Last-Event-ID 恢复与 sequence 连续；
- 长会话摘要、可选搜索降级、恶意网页注入隔离；
- 并发幂等、取消竞态、跨租户与未认证拒绝；
- DB 最终提交失败、Redis enqueue 失败、Worker crash/重复 delivery；
- 1/5/10 并发负载、预算/Tool/SSE 上限压力场景。

结果：20/20 通过。

### 3.2 真实浏览器全链

Playwright 启动临时 PostgreSQL、Redis、真实 NestJS app、Agent worker 和 Vite 前端后，完成：

1. 真实登录并保存 Refresh Cookie；
2. `/agent` 提问，真实 Worker/Tool/SSE/审计闭环；
3. Run 进行中刷新，按权威 sequence 恢复且不重复；
4. 真实取消后重新生成，旧 Run 保持 `CANCELLED`，新 Run 独立 `COMPLETED`。

结果：4/4 通过，浏览器 console 问题列表为空。

取消与模型完成存在合法竞态：如果模型响应已先完成，其审计可为 `SUCCEEDED`；产品不变量仍是旧 Run/assistant 只有 `CANCELLED` 终态、无成功回答落库，新 Run 使用独立 response message。

## 5. 缺陷与修复

| ID | 问题 | 修复 | 回归 |
| --- | --- | --- | --- |
| AG-LOCAL-001 | `WebsocketModule` 在独立模块图中缺少 `TokenService` | 显式导入 `SharedModule` | Agent E2E 20/20；WebSocket 单测通过 |

| AG-LOCAL-003 | 取消竞态断言错误要求模型必为 `CANCELLED` | 改为校验权威 Run/assistant 终态，并接受模型已完成竞态 | 连续多轮 E2E 通过 |

| AG-LOCAL-005 | 服务端隔离 E2E 二次硬编码 `pnpm exec jest` | 使用当前 Node 直接执行本地 Jest | 无 `pnpm` 依赖启动并通过 |
