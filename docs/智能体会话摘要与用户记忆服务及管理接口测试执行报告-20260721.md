## 1. 本轮目标

- 实现摘要提交、服务端 hash 和安全 metadata 映射。
- 实现用户记忆 list/create/update/delete，仅 POST、JWT owner、严格 DTO、显式确认。
- 用真实 PostgreSQL HTTP 链路验证事务、跨租户、来源、分页、并发和错误码。

## 2. 业务理解摘要

| 项目     | 结论                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 业务场景 | 用户查看、显式保存、纠正、删除长期记忆；会话详情展示可审计摘要 metadata          |
| 核心规则 | 身份只取 JWT；create 原子确认；update 追加版本；delete 即时排除；摘要正文不公开  |
| 关键风险 | 跨租户、确认绕过、candidate 半提交、敏感内容伪装、响应泄露、并发 active/版本冲突 |
| 待澄清   | 语义安全分类器、摘要生成模型和 P2 性能/压力在后续阶段                            |
