## 2. 缺陷与修复

### AG-20260805-001：模型审计幂等键缺少 Workflow Step

- 现象：工具预选成功后，规划节点抛出 `AgentAuditConflictError`，页面显示 Agent 内部错误。
- 根因：`ai_model_calls` 唯一键只包含 Run、模型、purpose 和 attempt；同一 Run 的两个 PLAN 节点发生碰撞。
- 修复：唯一键与仓储重试查询均加入 `stepId`，并新增迁移 `20260805020000_include_model_step_in_audit_idempotency`。
- 回归：真实 PostgreSQL 集成测试 11/11 通过；实际数据库索引已更新。

### AG-20260805-002：同层部分数据缺失触发整次研究失败

- 现象：精确日期历史行情无数据，但区间行情/股票概览已有事实，Workflow 仍直接失败。
- 根因：所有 required Tool 都采用 fail-fast，未区分“无任何事实”和“同层已有替代事实”。
- 修复：仅对 `DATA_NOT_FOUND` 延迟判定；同层有成功事实时降级为 warning，无成功事实时保持失败。
- 回归：Workflow 14/14 通过；真实成功 Run 中一个 Tool 失败、两个事实 Tool 成功，`execute_tools` 为 `COMPLETED`。

### AG-20260805-003：结构化回答连续触达输出长度

- 现象：SYNTHESIZE 连续两次输出 4915 tokens，均以 `finish_reason=length` 截断，页面等待约 133 秒后失败。
- 根因：repair 将整段截断废稿再次回灌，且旧回答 schema 允许正文、claims、引用与 warnings 的理论规模超过当前输出预算。
- 修复：
  - 长度截断时不再回灌废稿，repair 明确要求生成更短 JSON；
  - 发布 Workflow v10 / Prompt v8；
  - 回答协议限制为正文 3000 字符、10 个 claims、每个 claim 最多 4 个 factId、6 个 warnings；单股提示进一步要求 2000 中文字符以内。
- 回归：Model Gateway 与 v10 协议测试 23/23 通过；真实 Provider 输出 3269 tokens 并正常 `stop`。
