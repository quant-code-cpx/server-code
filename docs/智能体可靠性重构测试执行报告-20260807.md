## 9. 最终结论

6018 首要故障已消除：模型单次上下文/输出能力来自 Run 创建时冻结的部署配置，累计输入护栏是默认关闭的显式 Run 成本策略；成功调用只记账，超额只影响下一次调用前门禁。真实浏览器 117 条消息证明 32K 不再覆盖模型能力，同时也暴露并修复 6 类工作流/工具/引用问题。供应商 6005/6007 仍是外部风险，已真实记录，未宣称全部业务 Run 成功。
