## 2. 关键覆盖

- `AG-MVP-BIZ-002` 从 HTTP 到 Worker、Tool、模型、审计、POST-SSE 的闭环 scrape `agent_runs_total`、`agent_model_attempts_total`、`agent_tool_attempts_total` 与 `agent_trace_spans_total`。
- 模型成本使用 provider 成本优先、价格表回退和 unknown 三种路径；unknown 不被记成 0。
- 评测 dataset 固定 version/hash，并验证门禁回退会失败；管理员相同 idempotency key 只复用一个 evaluation run。
- trace/metrics 只记录受控元数据标签；不使用 user、Run、trace 或原始内容作为 Prometheus label。
- Prometheus 与 Grafana 使用 Compose 挂载 provisioning，告警规则使用 `promtool` 语法检查。
