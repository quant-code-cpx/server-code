## 1. 根因与修复

开发 Compose 的 API 服务固定 `PROCESS_ROLE=api`，条件订阅 processor 只会在 `worker/all` 角色注册；通用 `worker` 又被 `profiles: ['worker']` 隐藏，默认启动没有消费者。任务因此停留 Redis `wait`，不会创建执行日志或更新订阅。

已在 `docker-compose.yml` 移除 worker profile，默认启动 worker，并增加主进程存活 healthcheck。未修改 Tushare 数据或同步逻辑。
