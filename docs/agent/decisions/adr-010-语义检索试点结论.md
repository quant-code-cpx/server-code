# ADR-010：语义检索试点结论

- 状态：已接受（no-go）
- 日期：2026-07-23
- 关联批次：[Batch 027](../tasks/batches/batch-027-vector-retrieval-pilot.md)
- 替代关系：延续 [ADR-007](./adr-007-vector-database-necessity.md)，未引入新的生产向量存储

## 1. 决策

当前不在生产 PostgreSQL 启用 pgvector，不创建 `AiRetrievalChunk` migration/index，不生成真实用户正文 embedding。生产默认保持：

```text
AGENT_RETRIEVAL_MODE=fts
```

`ContextBuilder` 可使用带租户、状态、删除、过期和数据截止日过滤的 metadata + PostgreSQL FTS/确定性 substring baseline。`hybrid` adapter 仅是隔离试验入口；缺少完整 endpoint/key/model/dimension 配置时启动失败，运行期 embedding/pgvector 故障时回退 FTS。

## 2. 预设门禁

Go 必须同时满足，不能只凭单项质量改善：

1. 资格门禁：可检索的已确认报告/记忆超过 10 万条；当前架构约定未达到时不承担向量索引成本。
2. 质量门禁：固定 gold set 上 hybrid 的 Recall@K、MRR 改善达到数据集 manifest 阈值，且不是由人工 semantic tags 代替真实模型。
3. 延迟门禁：真实 embedding provider + pgvector 查询的 p95 不超过获批数据集阈值；离线内存 scorer 延迟不能替代。
4. 成本门禁：固定模型、维度、batch 和价格版本后，生成/更新成本进入获批预算；成本未知即失败。
5. 存储门禁：在 41 GB 数据库隔离克隆上完成 HNSW/IVFFlat build 时间、WAL、磁盘、备份、校验、恢复和删除演练。
6. 隐私门禁：跨租户命中为零；只处理用户明确确认的记忆/报告；结构化行情、持仓正文、未确认会话和 hidden reasoning 不向量化。

## 3. 证据

### 3.1 当前真实数据库

只读检查结果：

- 数据库大小：41 GB。
- extension：`plpgsql`、`pg_stat_statements`；无 `vector`。
- `ai_user_memories`：0 行。
- `ai_research_reports`：0 行。
- `ai_retrieval_chunks`：不存在。
- 空表 FTS baseline `EXPLAIN (ANALYZE, BUFFERS)`：Execution Time 0.107 ms；该结果仅证明 SQL 可执行，不代表有语料时 p95。

资格门禁直接失败：0 远低于 10 万条。

### 3.2 匿名合成质量集

数据集 `retrieval-v1@2026-07-23`，8 个匿名/合成 source、8 个 query，未包含行情表或真实用户正文。执行：

```bash
pnpm run eval:agent -- --suite=retrieval
```

结果：

| 策略 | Recall@3 | MRR |
| --- | ---: | ---: |
| metadata + FTS baseline | 0.25 | 0.25 |
| semantic tags 上界 fixture | 1.00 | 1.00 |
| 固定 0.35/0.65 hybrid 上界 | 1.00 | 1.00 |

质量上界显示同义表达可能受益，但 semantic tags 是人工上界，不是获批 embedding 模型结果，不能支持生产 Go。

### 3.3 临时 pgvector 容器

隔离 `pgvector/pgvector:pg16` 容器中完成：

- `CREATE EXTENSION vector`、三维 chunk 表和 HNSW 索引。
- FTS 与 vector 查询的 owner tenant 正分支。
- other tenant、deleted、stale chunk version、旧 model version 负分支。
- source 删除后 active chunk 为零。
- 容器测试后清理。

微型数据集的 `EXPLAIN` 未选择 HNSW，而选择唯一索引后排序；这进一步说明微型容器不能代替 41 GB 克隆的索引/WAL/备份门禁。

## 4. 安全与运行约束

- `user_id`、source status、`deleted_at`、expiry、chunk/model version 条件写入 SQL 本体，不能在应用层事后过滤。
- embedding 请求只发送有界、脱敏 query；日志仅记录 query SHA-256，不记录原文、向量或 key。
- hybrid score 固定由服务端权重计算，返回 FTS/vector/hybrid score components；模型不能调整排名公式。
- 结构化金融事实继续走注册 Tool，不进入报告/记忆 RAG。
- `RETRIEVAL_FALLBACK_FTS`、`RETRIEVAL_UNAVAILABLE`、`RETRIEVAL_TRIMMED` 进入 Context manifest warning。

## 5. 复审条件

仅当已确认可检索 source 超过 10 万条，并获得以下外部条件后复审：

1. 获批 embedding provider/model/version/dimension、endpoint allowlist、secret 和成本预算。
2. 真实但匿名化的 query→relevant source gold set。
3. 41 GB 数据库隔离克隆和 pgvector extension 试验授权。
4. 索引 build/WAL/backup/restore/删除演练窗口。

复审通过时新建 ADR 替代本 ADR，再新增 migration；不得直接把当前 `hybrid` 配置切入生产。
