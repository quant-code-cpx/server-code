## 3. 联网研究启用设计

### 3.1 复用现有安全链

```text
search_web
  -> WebSearchService
  -> BraveSearchProvider
  -> URL 规范化、域名过滤、来源分类
  -> Run/user 绑定 urlToken

fetch_web_page
  -> 验证 urlToken
  -> SSRF Policy + DNS/IP 校验
  -> SafeWebFetcherService
  -> 不可信纯文本、content hash、citation source
```

不得新增“模型直接传 URL 给 fetch”的捷径。关键事实必须经过 `search_web -> fetch_web_page`，搜索摘要本身不可引用。

### 3.2 环境配置

生产启用前配置：

```dotenv
AGENT_SEARCH_PROVIDER=brave
AGENT_SEARCH_API_KEY=<secret>
AGENT_URL_TOKEN_SECRET=<至少 32 字节 secret>
```

真实 secret 只放部署 secret/.env，不写入仓库。生产禁止 fake provider。

将两个 key 加入 `AGENT_TOOLS_ENABLED` 前必须运行 Provider 健康探测；Provider disabled 或缺 key 时应用 fail-fast，不能表现为“搜索成功但无结果”。

### 3.3 来源策略

按问题优先域名：

| 事实            | 优先来源                                   |
| --------------- | ------------------------------------------ |
| 交易所公告/规则 | `sse.com.cn`、`szse.cn`、`bse.cn`          |
| 监管政策        | `csrc.gov.cn`、`pbc.gov.cn`、`gov.cn`      |
| 公司公告        | 交易所/公司官网                            |
| 基金公告        | 基金公司/交易所                            |
| 新闻            | 主流媒体；必须标记 MEDIA，不能覆盖官方事实 |

搜索结果域名只是候选；抓取后仍按 sourceType、publishedAt、retrievedAt 和正文 hash 记录引用。

### 3.4 Tushare 新闻/公告判断

短期不增加 Tushare 新闻 Tool。官方 [新闻快讯](https://tushare.pro/document/2?doc_id=143) 和 [新闻通讯](https://tushare.pro/document/2?doc_id=195) 均需单独权限，与普通积分无关。未确认权限、版权、保留期和真实返回前，不设计在线 Agent 调用。

若中期购买权限，先建设独立本地 `NewsSyncModule`、去重/版权/保留期和全文检索，再评估 `get_structured_news`；不得把 Tushare 新闻 API 直接挂到 Agent Tool。

### 3.5 联网测试

- URL token 绑定 userId/runId、过期、篡改、跨用户重放均拒绝。
- localhost、内网 IP、重定向到内网、DNS rebinding、非 HTTP(S) 拒绝。
- Prompt Injection 只作为不可信正文和 warning，不能改变系统指令。
- snippet 不可引用；正文 sourceId 可引用。
- 超时、限流、429、空正文、超长正文、编码 fallback 均 typed。
- 引用必须能回到 canonical URL、retrievedAt 和 content hash。

## 4. `get_option_market@1`

### 4.1 v1 能力边界

v1 支持合约搜索、合约详情和日线历史。不承诺：

- 标的证券维度的完整期权链。
- 隐含波动率、Delta/Gamma/Vega/Theta。
- 分钟/实时行情。
- 自动策略推荐。

原因：当前 `OptBasic` 没有经过验证的 `underlyingCode`，`OptDaily` 只存 OHLC/结算/成交/持仓量。不能从合约名称猜标的并伪装为精确映射。

### 4.2 输入

| 字段                      | 类型     | 默认       | 约束                            |
| ------------------------- | -------- | ---------- | ------------------------------- |
| `operation`               | enum     | —          | 必填：`SEARCH,CONTRACT,HISTORY` |
| `optionCode`              | string   | —          | CONTRACT/HISTORY 必填，最长 30  |
| `nameQuery`               | string   | —          | SEARCH 可选，2–64 字符          |
| `exchange`                | enum     | —          | `SSE,SZSE,CFFEX,DCE,SHFE,CZCE`  |
| `callPut`                 | enum     | —          | `CALL,PUT`，映射真实源值        |
| `maturityFrom/maturityTo` | ISO date | —          | SEARCH；跨度最多 5 年           |
| `listedOnly`              | boolean  | true       | 以 asOfDate 判断生命周期        |
| `asOfDate`                | ISO date | 最近 READY | 可选                            |
| `startDate/endDate`       | ISO date | 最近 1 年  | HISTORY；跨度最多 5 年          |
| `page/pageSize`           | integer  | 1/50       | SEARCH：pageSize 1–100          |
| `maxSeriesPoints`         | integer  | 500        | 20–1,000                        |

Adapter 按 operation 拒绝缺失/无关字段。

### 4.3 输出

```ts
interface OptionContractData {
  optionCode: string
  name: string | null
  exchange: string | null
  seriesCode: string | null
  optionType: string | null
  callPut: string | null
  exerciseType: string | null
  exercisePrice: number | null
  contractMultiplier: string | null
  settlementMonth: string | null
  listDate: string | null
  maturityDate: string | null
  delistDate: string | null

interface OptionHistoryPoint {
  tradeDate: string
  preSettle: number | null
  preClose: number | null
  open: number | null

  low: number | null
  close: number | null
  settle: number | null

```

SEARCH 返回 total/page/items；CONTRACT 返回单合约；HISTORY 返回 coverage、totalPoints、returnedPoints、sampling 和 points。

规则：

- 合约是否上市：`listDate <= asOfDate <= delistDate/maturityDate`。
- `callPut` 映射保留原始 source value，未知值返回 null + warning。
- amount/vol/oi 单位按上游字段定义输出，未验证时标记 SOURCE_UNIT，不自行换算。
- HISTORY 只读本地；无最新数据返回 DATA_NOT_READY。

Policy：READ、PUBLIC_MARKET_DATA、20 秒、maxRows 2,000、cost MEDIUM。

## 6. `run_event_study@1`

### 6.1 固定事件目录

```text
FORECAST
DIVIDEND_EX
HOLDER_INCREASE
HOLDER_DECREASE
SHARE_FLOAT
REPURCHASE
AUDIT_QUALIFIED
DISCLOSURE
```

事件读取和第二批 `get_stock_events` 分工：前者计算样本集合的异常收益，后者列出原始结构化事件。

### 6.2 输入

| 字段                | 类型     | 默认        | 约束                                                |
| ------------------- | -------- | ----------- | --------------------------------------------------- |
| `eventType`         | enum     | —           | 必填，固定 8 类                                     |
| `tsCode`            | string   | —           | 可选；省略为市场样本                                |
| `startDate/endDate` | ISO date | 最近 3 年   | 最大跨度 10 年                                      |
| `preTradeDays`      | integer  | 5           | 0–20                                                |
| `postTradeDays`     | integer  | 20          | 1–60                                                |
| `benchmarkCode`     | enum     | `000300.SH` | `000300.SH,000905.SH,000852.SH,000001.SH,399006.SZ` |
| `minSamples`        | integer  | 10          | 1–100                                               |
| `maxSamples`        | integer  | 500         | 10–500                                              |
| `includeTopSamples` | boolean  | false       | 最多正负各 10 条                                    |

市场样本要求 `minSamples>=10`；指定单股时允许 1。

### 6.3 算法与输出

v1 固定市场调整法：

```text
AR[i,t] = stockReturn[i,t] - benchmarkReturn[t]
CAR[i,t] = sum(AR[i,-pre..t])
AAR[t] = mean(AR[i,t])
CAAR[t] = mean(CAR[i,t])
```

输出：

```ts
interface EventStudyToolData {
  eventType: string
  eventLabel: string
  requestedRange: { startDate: string; endDate: string }
  actualEventRange: { startDate: string | null; endDate: string | null }
  benchmarkCode: string
  preTradeDays: number
  postTradeDays: number
  sampleCount: number
  excludedSampleCount: number
  exclusionReasons: Record<string, number>
  aarSeries: Array<{ relativeDay: number; value: number | null; sampleCount: number }>
  caarSeries: Array<{ relativeDay: number; value: number | null; sampleCount: number }>
  finalCar: {
    mean: number | null
    median: number | null
    positiveRate: number | null
    tStatistic: number | null
    pValue: number | null
  }
  topPositiveSamples: EventStudySample[] | null
  topNegativeSamples: EventStudySample[] | null
  algorithmVersion: 'event-study.market-adjusted.v1'
}
```

规则：

- 事件以公告可得日/真实事件定义为准，定义 hash 写入 provenance。
- 同股票同日同事件去重；样本不足返回 DATA_NOT_READY。
- 缺少行情、基准、窗口不足的样本排除并统计原因。
- `maxSamples` 超出时按 `hash(eventId + algorithmVersion)` 确定性抽样，保证重放一致。
- pValue/t-test 方法和小样本警告固定；统计显著不等于经济可交易。
- 不允许模型传任意事件 SQL、回调函数或基准。

Policy：READ、PUBLIC_MARKET_DATA、60 秒、maxRows 5,000、cost HIGH；一次 Run 最多 2 次。

## 8. Workflow v8 路由

- 最新新闻/规则/网页事实：先 search，再 fetch 正文。
- 本地结构化公司事件：第二批 `get_stock_events`，不联网。
- 事件平均影响：`run_event_study`，不调用网页。
- 期权/转债行情：本批本地 Tool，禁止搜索摘要替代行情。
- 当前未实现的期权 Greeks：明确 capability gap，不让模型自行编造。

能力包：`EXTERNAL_EVENT` 和 `DERIVATIVES`。联网 pack 只有用户请求最新/外部信息或本地结构化数据不足时选择。

## 9. 测试与验收

### 9.1 衍生品

- 合约生命周期边界、到期/退市过滤、未知 callPut。
- 期权 HISTORY 日期和 OHLC 单位，禁止出现未存储 Greeks。
- 转债上市/退市、正股映射、转换价和溢价率 null。
- 转债短覆盖明确 warning；准入后抽测至少 100 只活跃转债。
- Resolver 股票/基金/期权/转债同代码前缀不串型。

### 9.2 事件研究

- 用可手算股票/基准收益验证 AR、CAR、AAR、CAAR。
- 公告日晚于研究 asOf 的事件不进入样本。
- 停牌/缺行情/窗口不足排除原因准确。
- 确定性抽样相同输入/数据版本输出 hash 相同。
- 非 owner 数据不涉及；全部为公共研究。

### 9.3 联网

执行第 3.5 节安全矩阵；再以交易所规则和公司公告各 10 个真实问题验证引用。

## 10. 发布与回滚

发布顺序：受控搜索灰度 → 期权 → 转债（回补达标后）→ 事件研究。五个能力独立开关，不要求同时启用。

回滚：

- 搜索：移除两个 key 并把 Provider 设回 disabled。
- 衍生品/事件：移除对应 key，Workflow 回切 v7。
- 保留本地数据和无破坏性同步改进。
- 已持久化 v8 Run 按冻结 Tool pin 重放。

完成定义：联网证据可引用且安全，衍生品只返回真实存储字段，转债覆盖达标，事件研究可复现，所有缺口均明确而非模型补造。
